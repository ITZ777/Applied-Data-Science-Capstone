# Welcome to my SpaceX Falcon 9 Launch Outcome Prediction Project. Below is an overview of the key achievements and insights gained throughout this project!
• Conducted detailed data analysis on 100+ SpaceX Falcon 9 launches, predicting the successful landing of first-stage booster using Decision Tree Classifier, achieving an impressive accuracy rate of 87%. 
•	Performed exploratory analysis using SQL Queries on a DB2 Database to extract & sort data for meaningful patterns
•	Built dashboard to analyze launch records using Plotly Dash, interactive map for launch site proximity with Folium
